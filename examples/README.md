# Examples

This directory is the recommended starting point for new users.

## Layout

- `examples/scripts/`: plain Python scripts that can be run from the command line
- `examples/notebooks/`: mirrored notebooks for guided exploration

## Suggested order

1. `01_h2_ground_state`
2. `02_h4_compare_solvers`
3. `03_n2_intro_active_space`

All three are meant to be easy to read and to land at or below `1 mEh`
accuracy on the bundled toy systems.

For the current large-`N2` production benchmark answer, see:

- `docs/fixed_budget_results.md`
