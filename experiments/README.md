# Experiments

This directory stores artifact locations and short notes for reproducibility.

It is **not** part of the beginner learning path.

## What belongs here

- saved sweep outputs
- benchmark notes
- reference summaries
- run directories used for method development

## What does not belong here

- the first examples for new users
- core package documentation
- reusable source code

## Current guidance

For new users:

- start in `examples/`

For advanced users:

- use the drivers under `scripts/advanced/`
- treat this directory as artifact storage
